Storage location

Browser storage

Choose the same folder in localhost and the hosted app. Existing folder data is loaded before autosave starts. Connected tabs refresh on focus and check for changes every 2 seconds. Edit in one version at a time. Browser autosave remains a recovery copy.

The browser displays the folder name, not its full path. It may ask for permission again after reopening. Folder selection works in supported desktop browsers such as Chrome and Edge.
